## 📌 Project Overview
Safe Haven Animal Rescue is a registered non-profit organization (NPO) web application dedicated to rescuing, rehabilitating, and rehoming vulnerable dogs and cats across South Africa. The primary objective of this site is to drive community involvement, streamline pet adoptions, register foster caregivers, and secure sponsorship to support ongoing shelter operations.


## 🎯 Website Goals and Objectives
* **Promote Animal Welfare:** Educate the public on humane animal care, responsible pet ownership, and community spay/neuter initiatives.
* **Facilitate Adoptions:** Provide transparent profiles of rescued animals to connect them with suitable forever homes.
* **Volunteer & Sponsor Engagement:** Provide structured online forms to recruit volunteers and secure organizational sponsorships.
* **Multi-Branch Accessibility:** Ensure clear access to location details, contact information, and operating hours across multiple shelter facilities.


## ⚡ Key Features and Functionality
* **Global Navigation:** A consistent navigation menu across all 5 pages (`index.html`, `about.html`, `services.html`, `enquiry.html`, `contact.html`).
* **Semantic HTML5 Structure:** Built using proper structural tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **Interactive Forms:**
  * **Volunteer & Sponsor Enquiry Form (`enquiry.html`):** Includes structured input fields, select dropdowns, checkboxes, and textareas with field validation attributes.
  * **General Contact Form (`contact.html`):** Direct message inquiry form for general shelter questions.
* **Multi-Branch Contact Information:** Detailed physical addresses, emails, and operating hours for both Cape Town and KZN shelter branches.
* **Accessible Media Content:** Image tags with descriptive `alt` attributes to meet web accessibility standard requirements.
